### Task 1: Import-Rückfrage, Steuerzeichen, Ablage-Schutz, Export-Grenze

**Files:** Modify `src/shared/presets.ts`, `src/shared/types.ts`, `src/main/presets.ts`, `src/main/ipc.ts`; Test `test/presets.test.ts`, `test/presets-datei.test.ts`

**Interfaces:**
- `type NetzWahl = 'uebernehmen' | 'ohne' | 'abbrechen'` (types.ts)
- `importiere(vorhanden, text, frage, netzFrage: (netzwerk: { name: string; dir: string }[]) => Promise<NetzWahl>)` — `netzFrage` nur, wenn `netzwerk` nicht leer, NACH der Konflikt-Frage (endgültige Namen), VOR dem Ergebnis. `'ohne'` → bei genau diesen (importierten, endgültig benannten) Presets fällt `werte.dir` weg; `'abbrechen'` → `{ ok: false }`.
- Meldung: übernommen → `… – N davon mit Netzwerkordner.` (wie 0.9.0); ohne → `… – N ohne Netzwerkordner übernommen.`
- `netzwerkHinweis(netzwerk)` → `{ message, detail }`; Steuerzeichen in Name/Pfad (`/[\x00-\x1f\x7f]/g`) durch Leerzeichen ersetzt; Schlusssatz `Nur übernehmen, wenn dieser Ordner bekannt ist – beim Anwenden meldet sich Windows bei diesem Server an.`
- `ipc.ts` `presets:importieren`: `netzFrage` = `showMessageBox({ type: 'warning', buttons: ['Übernehmen', 'Ohne Netzwerkordner übernehmen', 'Abbrechen'], defaultId: 1, cancelId: 2, ...netzwerkHinweis(...) })`; der Warn-Dialog NACH dem Speichern entfällt.
- `speicherePresets`: liegt schon eine Datei mit `version > 1`, wirft es `Die Preset-Datei stammt aus einer neueren Recorder-Version – nicht überschrieben.` (der Store zeigt das schon über seinen Fang).
- `baueExportDatei`: mehr als 500 Presets → wirft `Zu viele Presets für eine Datei (höchstens 500).` (dieselbe Grenze wie beim Import, eine Konstante).

- [ ] Tests zuerst: `'ohne'` mit Konflikt „Überschreiben“ (Review Focus 1) und mit „Beide behalten“ („A (2)“ ohne Ordner, „A“ unverändert); `'abbrechen'` → `ok:false` ohne Fehler; `'uebernehmen'` → Ordner bleibt; keine Netzwerkpfade → `netzFrage` nicht gerufen; Name mit `\n` → Detail ohne Zeilenumbruch im Namen; v2-Datei vorhanden → `speicherePresets` wirft, Datei unverändert; 501 Presets → `baueExportDatei` wirft.

### Task 2: Stille — Bestätigung mit Frist, Stopp nach Stau, disarm robust

**Files:** Modify `src/main/stille.ts`, `src/main/recorder.ts`; Test `test/stille.test.ts`, `test/recorder.test.ts`

**Interfaces (StilleUhr):**
- Bestätigung trägt eine Zeit: `fehlend(jetzt)` setzt bei Pause `bestaetigtMs = jetzt`; `block()` füllt nur, wenn `bestaetigtMs !== null && jetzt − bestaetigtMs < STILLE_PAUSE_MS`; danach `bestaetigtMs = null`. `weiter()` setzt `bestaetigtMs = null`.
- Neu `letzterEchterBlockMs` (nur `block()` setzt ihn, `weiter()` nicht) und `fehlendBeimStopp(jetzt): number` = `jetzt − letzterEchterBlockMs ≥ STILLE_PAUSE_MS ? max(0, erwartet − geschrieben) : 0`. `stopRecording`/`disarm` benutzen `fehlendBeimStopp` statt `fehlend`.
- `disarm`: `multiWriter.finalize()` in try/catch (Fehler schlucken, Eingang trotzdem schließen).

- [ ] Tests zuerst (`stille.test.ts`): `fehlend(1300)=300`, `aufgefuellt(300)`, `block(10, 1800)` → `0` (alte Bestätigung); `fehlend(1300)`, `aufgefuellt(300)`, `block(10, 1350)` → `40`; Block bei 1000 (1000 Frames), `weiter(1200)`, `fehlend(1300) === 0` aber `fehlendBeimStopp(1300) === 300`. Bestehende Erwartungen (300/50/690/600) bleiben. (`recorder.test.ts`): 450 ms echte Stille (Wächter füllt), 400 ms Busy-Wait, 40 Nicht-Null-Blöcke → erster Nicht-Null-Frame liegt bei ≈ gemessener Stilledauer (±80 Frames bei 1000 Hz), nicht danach.
- [ ] RED sehen → umsetzen → Selbsttest grün, typecheck 0
- [ ] Commit `fix(recorder): Stille nur nach frischer Bestätigung einschieben, Stopp nach Stau vollständig`

### Task 3: Store — „(geändert)“ nach Preset-Feldern, Vorbehalt, Warteschlange, Reihenfolge, Show-Ordner

**Files:** Modify `src/shared/presets.ts` (eine Vergleichsfunktion), `src/renderer/src/store/recorder.ts`; Test `test/presets.test.ts`, `test/store.test.ts`

- **„(geändert)“**: neu `gleicheDefinierteWerte(aktuell, preset): boolean` in `shared/presets.ts` — vergleicht nur die Felder, die `presetWerte(preset)` enthält. `presetGeaendert` benutzt sie. (Preset ohne Ordner/Eingang zeigt danach kein „(geändert)“ und kein „Zurücksetzen“ mehr.)
- **Vorbehalt**: `setChannels`/`setSampleRate` (Bedienung + Preset ohne Eingang) beenden einen Vorbehalt (`vorbehalt = null`); die Show-Vorgaben (`applyShowSettings`) setzen Kanäle/Samplerate direkt mit derselben Begrenzung und lassen den Vorbehalt stehen.
- **Warteschlange**: `presetAbwaehlen` erhöht `anwendenNr` (ein wartendes Anwenden entfällt) und setzt `aktivesPreset = null`.
- **Reihenfolge**: in `wendeAn` Schließen/Öffnen VOR der `ordnerDa`-Abfrage (ein unerreichbares NAS hält den Gerätewechsel nicht auf).
- **Show-Ordner**: setzt `applyShowSettings` einen Netzwerkpfad als `dir`, steht oben `hinweisOrdner: 'Zielordner aus der Show liegt im Netzwerk: <dir> – nur verwenden, wenn dieser Ordner bekannt ist.'`
