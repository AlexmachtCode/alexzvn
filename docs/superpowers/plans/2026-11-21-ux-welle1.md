# UX-Update Welle 1 „Live-Kern“ — Implementierungsplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Switcher, Timer, Rundown, Q&A und Battle bekommen den Rahmen und das Bediengefühl des Titler-Piloten:
- `AppShell` mit Kopfzeile, Statusleiste und Einstellungs-Panel;
- `TallyButton`-Haupttasten;
- Abschnitte aus `@jm/settings`;
- Hell/Dunkel.

Dabei geht keine Funktion und kein Kürzel verloren.

**Architecture:**
- **Je App:** Zuerst entsteht eine Funktionsliste aus dem Code. Danach kommen Status-Brücken (Master-Link im Preload, Fernsteuerungs-Meldung aus dem Steuerserver) und das Testwerkzeug.
- **Ableitungen:** Eine reine Ableitungsschicht `lib/oberflaeche.ts` liefert Statusleiste, Panel-Abschnitte, Haupttasten und Texte. Statusleiste und Panel nutzen dieselbe Wahrheit.
- **Aufbau:** Die Oberfläche baut daraus `AppShell`, Live-Bereich und Panel. Am Ende wird die Funktionsliste abgehakt.
- **Unverändert** bleiben die Bedienlogik, die Protokolle, die Ports, die IPC-Befehle und die Ausgabefenster.

**Tech Stack:**
- Electron, React 18, TypeScript, Tailwind v4, zustand;
- `@jm/ui`, `@jm/settings` und `@jm/app-runtime` aus dem Monorepo;
- Tests: `tsx` mit `renderToStaticMarkup` (`@jm/ui/testhilfe`), dazu die Bestandstests unter `node --experimental-strip-types`.
