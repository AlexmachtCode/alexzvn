# Studio Checkliste – Betrieb & Vorbereitung

*Jakobs Medien GmbH – Technik Wiki Version*

---

## 1. Allgemeine Vorbereitung

- [ ] Studio ist aufgeräumt, Kabelwege frei
- [ ] Alle Geräte haben Strom / PoE++ / USV
- [ ] Netzwerk aktiv (Switches, VLANs, PoE)
- [ ] Monitoring-Systeme laufen (Multiview, Audio-Metering)
- [ ] Letzte Änderungen im Technik-Wiki geprüft

---

## 2. Licht – Checkliste

### 2.1 Hardware

- [ ] Aputure Nova P300C eingeschaltet
- [ ] LS300X & LS60X aktiv
- [ ] Softboxen korrekt montiert
- [ ] Snapgrid / Diffusion korrekt gesetzt
- [ ] ArtNet Node IV online

### 2.2 Steuerung

- [ ] QLC+ gestartet
- [ ] DMX‑Universen korrekt gepatcht
- [ ] Presets geladen (Keylight, Fill, Backlight, Szenen)
- [ ] Keine Fehlermeldungen im ArtNet‑Monitor

---

## 3. Video – Checkliste

### 3.1 PTZ‑Kameras

- [ ] PTZ Control Center geöffnet
- [ ] AW‑UE150 / UE100 erreichbar (Ping)
- [ ] IP‑Adressen stimmen (192.168.10.20–23)
- [ ] PoE++ aktiv
- [ ] Presets geladen (Wide, Close, Speaker, Panel) - [ ] Remote Panel AW‑RP150 verbunden

### 3.2 Cine‑Kameras

- [ ] URSA Mini Pro 12K betriebsbereit
- [ ] Sony FS5 & A7c korrekt konfiguriert - [ ] Opt
